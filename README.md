# ABG Motors Market Entry Analysis

## Project Overview
This project analyses the potential market entry of ABG Motors into India using customer data, machine learning and Tableau.

## Objectives
- Analyse Japanese customer data
- Build a Logistic Regression model
- Evaluate model performance
- Predict potential Indian customers
- Develop an interactive Tableau dashboard

## Tools Used
- Python
- Pandas
- Scikit-learn
- Excel
- Tableau
- Google Colab

## Project Files
- Final Report
- Indian Prediction Results
- Indian Dataset
- Japanese Dataset
- Tableau Dashboard
- Google Colab Notebook

## Key Result
The model predicted 69,289 potential purchasers among 70,000 Indian customer records.

## Dashboard
Tableau dashboard was developed to visualise customer characteristics and predicted purchase behaviour.
